# REFLEX BLOOM

光った瞬間をタップして反応時間を測り、その結果で小さな光を育てるPC・スマホ対応ブラウザゲームです。

公開版: https://kouheyhey.github.io/reflex-growth/

二作目の検証ケースとして、粗いユーザー入力から仕様、実装、評価、必須人レビュー待ちまでをゲーム自動生成フローで通しています。

## 遊ぶ

Node.js 20以降だけで動作し、パッケージのインストールは不要です。

```sh
npm run dev
```

PCでは起動時に表示されるLocal URL、同じWi-FiのスマホではMobile URLを開きます。既定ポートは4181です。

- 最初のタップ: 測定開始
- `WAIT…`: 押さずに待つ
- `TAP!`: すぐタップ
- 結果画面のタップ: 待ち時間なしで次の測定
- SOUNDボタン: 生成音のON/OFF

XP、レベル、ベスト、直近10回、最高連続数はブラウザへ保存されます。ブラウザデータを消すと育成状態も消えます。

## 検証

```sh
npm test
npm run review:auto
npm run validate:pipeline
npm run build
npm run review:gate
```

自動レビューは600試行をシミュレーションし、通常反応、早押し、時間切れ、測定値の非補正、育成到達性、主体性、即時再試行を検査します。

`review:gate` は自動評価が通っていても、必須11カテゴリの人レビューが完了するまで公開を拒否します。

## 設計上の重要点

- 実測反応時間は育成状態で補正しない
- 合図の表示と測定確定を分離し、プレイヤー入力だけが記録を確定する
- 結果表示と次試行受付を分離し、操作不能時間を0msにする
- 市場調査は未実行のまま明示し、生成した判断を市場事実として扱わない
- 「面白さ」「待機の緊張感」「育成実感」「端末遅延」は人が試遊する

## 構成

- `src/engine.js`: 測定、成長、履歴、永続化用データ変換
- `src/player-agency.js`: プレイヤー確定入力の共通契約
- `src/responsiveness.js`: 次操作可能時間の共通契約
- `src/interaction-contracts.js`: 本作固有の契約インスタンス
- `src/main.js`: 入力、表示、音、振動、ローカル保存
- `src/effects.js`: 成功時のCanvas演出
- `automation/`: 入力から公開待ちまでの生成成果物
- `docs/GENERATION_REPORT.md`: 二作目で確認できた再利用性

## 現在のAutomation Level

Level 4相当です。粗い入力の構造化、仕様化、実装、テスト、ビルド、公開プレビューまで接続しています。

市場調査、外部AI API、実公開、公開後分析は未実装です。自動レビューはpassしていますが、人による試遊と公開内容の承認が未完了のため公開できません。
